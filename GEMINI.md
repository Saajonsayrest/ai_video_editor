# Project instructions (Gemini / Antigravity)

## RULE (strict): log every decision

Record every non-trivial decision (video format/look/color/timing/content/text/music, tooling,
assets, scope) in [`DECISIONS.md`](./DECISIONS.md) — always, unprompted. Newest first, under a
`## YYYY-MM-DD` heading, one plain-language line each: `**HH:MM** — <simple decision>`. No jargon.

See [`AGENTS.md`](./AGENTS.md) for the full shared rule.
